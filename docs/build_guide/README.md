# BLIPR build guide (exported copy)

A Markdown copy of the live build guide, last updated Nov 9, 2026 (same edits as the live doc). The export leaves out pictures; each
one shows as a placeholder like `[image: …]`. The pictures themselves are in this repo:

- Wiring pictures: `pictures/out/`
- Circuit board drawings: `pcb/out/` (pcb_assembly.png, gerber_view_top.png, gerber_view_bottom.png)
- Case, lid, pod and assembly pictures: `case/out/`; the v0.11 side-wall drawing is `docs/img/case_base_walls.png`

Order: 1 build guide, 2 wiring pictures, 3 circuit board, 4 firmware, 5 sensors.
